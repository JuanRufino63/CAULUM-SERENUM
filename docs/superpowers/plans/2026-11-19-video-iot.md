# CAULUM SERENUM IoT Video Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produzir um MP4 Full HD de aproximadamente 90 segundos, com seis cenas animadas, seis locuções e uma demonstração real editada do Wokwi.

**Architecture:** Uma composição Remotion de 2704 frames usa seis `Sequence`s contíguas. Cada cena encapsula sua narrativa visual, enquanto componentes compartilhados fornecem fundo, tipografia, cartões e transições; os áudios são reproduzidos a 1,1× para sincronizar a duração total.

**Tech Stack:** Remotion 4, React 19, TypeScript, `@remotion/media`, SVG/CSS, FFmpeg incluído no Remotion.

**Spec:** `docs/superpowers/specs/2026-11-19-video-iot-design.md`

## Global Constraints

- Saída: MP4 1920×1080, 30 FPS, aproximadamente 90 segundos.
- Não apresentar API, aplicativo funcional ou integração remota.
- Identificar a interface como conceitual e os dados como simulados.
- Tratar os limiares como demonstrativos, não clínicos.
- Usar apenas os seis áudios e a captura Wokwi fornecidos pelo usuário.

## Review Focus

- Todas as locuções devem terminar antes do fim das respectivas cenas.
- Nenhuma cena pode ultrapassar a área segura ou cortar textos em 1920×1080.
- A gravação Wokwi precisa exibir estados reais normal, atenção e crítico.
- A interface conceitual não pode sugerir recebimento de dados do ESP32.
- O arquivo final precisa conter vídeo H.264, áudio AAC e duração próxima de 90 segundos.
